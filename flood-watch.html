เรื่องความแม่นยำและขอบเขต: ข้อมูลฝน/อากาศดึงจาก Open-Meteo (ฟรี ไม่ใช้คีย์) ทั้งพยากรณ์และย้อนหลัง 3 วัน ส่วน "ระดับความเสี่ยง" คำนวณจากเกณฑ์ปริมาณฝนรายวันของกรมอุตุนิยมวิทยา (เบา/ปานกลาง/หนัก/หนักมาก) รวมกับฝนสะสม 3 วัน (ตัวแทนความอิ่มตัวของดิน/ความเสี่ยงน้ำล้น) — เป็นเกณฑ์ประมาณการ ไม่ใช่ตัวเลขทางการจากกรมชลประทาน/ปภ. จึงควรใช้ประกอบกับประกาศทางการเสมอ ไม่ใช่แหล่งเดียวในการตัดสินใจ

กล้อง CCTV และข้อมูลระดับน้ำทางการ: หน้านี้ยังไม่ฝังวิดีโอ/ข้อมูลสดจากหน่วยงานโดยตรง (ติด CORS/สิทธิ์การใช้งานของแต่ละเว็บ ต้องทดสอบจริงจากเบราว์เซอร์ในไทยก่อนฝัง) จึงให้เป็นลิงก์ไปหน้าทางการแทน — เป็นรายการที่ยังพัฒนาต่อได้

การแจ้งเตือน: ปุ่ม "เปิดการแจ้งเตือน" ใช้ Web Notification API ทำงานเฉพาะขณะเปิดแท็บนี้ค้างไว้บนอุปกรณ์เครื่องนี้เท่านั้น การแจ้งเตือนแบบ push ไปมือถือแม้ปิดแอป ต้องมี backend/server แยกต่างหาก (ยังไม่ได้ทำในเวอร์ชันนี้ — เป็นขั้นต่อไป)

ตำแหน่งจังหวัดบนแผนที่ เป็นพิกัดโดยประมาณของศูนย์กลางจังหวัด ใช้สำหรับภาพรวมเท่านั้น หากต้องการความแม่นยำระดับพื้นที่ ให้ใช้ปุ่ม "ใช้ตำแหน่งของฉัน" หรือค้นหาสถานที่โดยตรง
