# 🌦️ พยากรณ์อากาศเจาะจงพื้นที่

แดชบอร์ดพยากรณ์อากาศแบบ real time เจาะจงทีละจุด (ใส่พิกัดแปลงหรือค้นหาจากชื่อได้) — เริ่มต้นที่แปลงมะพร้าวคลองวาฬ (อ.สามร้อยยอด จ.ประจวบคีรีขันธ์)
พื้นที่ที่ติ๊กว่าเป็นแปลงมะพร้าวจะมีการวิเคราะห์ความต้องการน้ำเพิ่ม
เป็นเว็บ static ล้วน (ไม่มี backend ไม่มี build step) โฮสต์บน GitHub Pages

**🌐 Live:** https://nub-1.github.io/khlongwan-weather/

## 🌊 หน้าเฝ้าระวังน้ำท่วมทั่วไทย

**🌐 เปิดหน้านี้:** https://nub-1.github.io/khlongwan-weather/flood-watch.html
(มีลิงก์สลับไปมากับหน้าพยากรณ์ฝนนี้)

หน้าเว็บแยกสำหรับติดตามสถานการณ์น้ำท่วม/ฝนทั่วประเทศไทย ครอบคลุมทุกจังหวัด ประกอบด้วย:

- 📍 **ใช้ GPS ระบุตำแหน่งตัวเอง** — กดปุ่ม "ใช้ตำแหน่งของฉัน" แล้วระบบจะหาจังหวัดที่ใกล้ที่สุดให้อัตโนมัติ
  หรือเลือก/ค้นหาพื้นที่เองก็ได้
- 🤖 **ผู้ช่วยวิเคราะห์สถานการณ์น้ำ** — วิเคราะห์แนวโน้มฝนวันนี้/พรุ่งนี้ + ฝนสะสม 3 วัน แล้วให้ระดับความเสี่ยง
  (ปกติ / เฝ้าระวัง / เตือนภัย / วิกฤต) พร้อมคำแนะนำการเตรียมตัวที่เหมาะกับแต่ละระดับ
  > ⚠️ เป็น**ระบบกฎ (rule-based) ที่รันในเบราว์เซอร์** อิงเกณฑ์ปริมาณฝนของกรมอุตุนิยมวิทยา
  > ไม่ใช่โมเดลภาษา AI/LLM — เพื่อความโปร่งใส หน้าเว็บระบุเกณฑ์ที่ใช้ไว้ท้ายหน้าเสมอ
- 🗺️ **แผนที่ทั่วประเทศ** (Leaflet + OpenStreetMap) แสดงหมุด 77 จังหวัด ไล่สีตามระดับความเสี่ยง
  กดหมุดเพื่อโหลด/ดูรายละเอียดพื้นที่นั้น ๆ ได้
- 📶 **เทียบหลายโมเดลพยากรณ์** (ECMWF/GFS/ICON/JMA) ว่าเห็นตรงกันกี่โมเดลว่าพรุ่งนี้จะมีฝนหนัก
- 🗂️ **รวมลิงก์แหล่งข้อมูลทางการ + กล้อง CCTV สาธารณะ** แยกหมวด จราจร / แม่น้ำ-คลอง / ทะเล / รายงานจากประชาชน
  (Longdo Traffic, กรมทางหลวง, EXAT, ThaiWater, กรมชลประทาน, กรมอุตุฯ, กรมเจ้าท่า, Traffy Fondue, ปภ.)
- 📞 **เบอร์โทรฉุกเฉิน** กดโทรได้ทันที (1784 ปภ., 191 ตำรวจ, 199 ดับเพลิง, 1669 การแพทย์ฉุกเฉิน ฯลฯ)
- 🔔 **แจ้งเตือนในแอป** ผ่าน Web Notification API เมื่อพื้นที่ที่เลือกเข้าสู่ระดับ "เตือนภัย" ขึ้นไป

### ข้อจำกัดที่ควรรู้ (โปร่งใสไว้ก่อน)

- กล้อง CCTV และข้อมูลระดับน้ำจากหน่วยงาน (ThaiWater, กรมชลประทาน ฯลฯ) ยังเป็น**ลิงก์ไปหน้าทางการ**
  ไม่ได้ฝังวิดีโอ/ดึงข้อมูลสดมาแสดงตรง ๆ เพราะแต่ละเว็บมีข้อจำกัดเรื่อง CORS/สิทธิ์การใช้งาน
  ที่ต้องทดสอบจริงจากเบราว์เซอร์ในไทยก่อนถึงจะฝังได้อย่างน่าเชื่อถือ — เป็นสิ่งที่พัฒนาต่อได้
- การแจ้งเตือนทำงานเฉพาะตอนเปิดแท็บ/หน้าเว็บค้างไว้บนอุปกรณ์เครื่องนั้น การแจ้งเตือนแบบ push
  ไปมือถือแม้ปิดแอป ต้องมี backend/server (web push + service worker) ซึ่งหน้านี้เป็น static site
  ไม่มี backend จึงยังไม่รองรับ
- ตำแหน่งจังหวัดบนแผนที่เป็นพิกัดโดยประมาณของศูนย์กลางจังหวัด ใช้เพื่อภาพรวมเท่านั้น
- "ระดับความเสี่ยง" เป็นเกณฑ์ประมาณการจากปริมาณฝน ไม่ใช่ตัวเลขทางการ ควรใช้ประกอบกับประกาศทางการเสมอ

## สิ่งที่หน้านี้ตอบ (v2.1)

1. **ตอนนี้ฝนตกไหม / ฝนกำลังจะเข้าไหม** — ใช้เรดาร์ตัดสิน และคำนวณเวลาที่ฝนจะมาถึงจากการเคลื่อนที่ของเมฆฝน
2. **แผนที่เรดาร์เคลื่อนไหว** — ไทม์ไลน์ −6 ถึง +6 ชม.: เรดาร์จริง 2 ชม. ล่าสุด (เท่าที่ RainViewer ฟรีเก็บไว้), คาดการณ์จากเรดาร์ 1 ชม. ข้างหน้า (เลื่อนภาพล่าสุดตามทิศที่ฝนเคลื่อน) และฝนรายชั่วโมงจากแบบจำลอง Open-Meteo (กริด 7×7 จุด ห่าง ~30 กม.) สำหรับช่วงที่เหลือ ทุกภาพติดป้ายบอกแหล่ง พร้อมวงรัศมี 10/25 กม. และลูกศรทิศที่เมฆฝนเคลื่อนเข้ามา
3. **ฝนก้อนถัดไปเริ่มกี่โมง** — บอกเป็น*ช่วงเวลา* ไม่ใช่เวลาเดียว
4. **บทวิเคราะห์อัตโนมัติ** — สรุปจากข้อมูลทั้งหมด: ช่วงแล้ง/ฝนชุก, วันที่ฝนหนักสุด, ช่วงเวลาของวันที่ฝนมักตก,
   ระบบพยากรณ์เห็นตรงกันไหม, เทียบสัปดาห์ก่อน, บรรยากาศไม่เสถียร, ผลย้อนทดสอบ (กฎตายตัว ไม่ใช่ AI)
5. **48 ชั่วโมงข้างหน้า** — โอกาสฝนรายชั่วโมง + กราฟอุณหภูมิ ความชื้น ลม เมฆ (แตะเพื่อดูค่า)
6. **7 วันข้างหน้า** รายวัน (แยกดึก/เช้า/บ่าย/ค่ำ) · **ตารางสีเทียบ ECMWF / GEFS / ICON** ว่าเห็นตรงกันไหม
7. **ฝนสะสม 7 วัน** — กราฟช่วงความไม่แน่นอน (50% / 80%) และโอกาสที่ฝนรวมจะถึง 10 / 25 / 50 มม.
8. **ต้องรดน้ำมะพร้าวไหม** — เทียบฝนกับเป้า 50 มม./สัปดาห์ พร้อมโอกาสได้ฝนครบเป้า และแผนสำรองกรณีฝนน้อยกว่าคาด
9. **โมเดลไหนแม่นที่จุดนี้** — ย้อนทดสอบ 30 วัน พร้อมกราฟทายถูก / เตือนผิด / พลาด แยกรายโมเดล

แถบเมนูด้านบนกดข้ามไปแต่ละส่วนได้ · เลขเวอร์ชันอยู่ท้ายหน้า

## ความแม่นยำ: ปรับอะไรบ้าง และทำไม

แปลงอยู่ชายฝั่ง ฝนส่วนใหญ่เป็นฝนพาความร้อน เซลล์กว้างแค่ 1–5 กม. แต่โมเดลที่ครอบคลุมไทยละเอียดสุดราว 11–25 กม.
จึง**ไม่มีแหล่งฟรีใดบอกล่วงหน้าหลายชั่วโมงได้ว่า "ตกบนแปลงนี้"** — สิ่งที่ทำได้คือใช้ข้อมูลให้ถูกประเภทกับช่วงเวลา และไม่แสดงความมั่นใจเกินจริง

| อาการที่เจอ | สาเหตุ | สิ่งที่แก้ |
|---|---|---|
| พยากรณ์ว่าฝนตก แต่ไม่ตก | โมเดลกริดหยาบให้ละอองฝนเกินจริง + นับ ≥ 0.1 มม. เป็นวันฝน | เกณฑ์วันฝน ≥ **1 มม.** (WMO) ชั่วโมงฝน ≥ **0.3 มม.** · ไม่แสดง 0%/100% ตรง ๆ (>99% / <1%) |
| ไม่พยากรณ์ แต่ฝนตก | โมเดลมองไม่เห็นเซลล์ฝนเล็ก | เรดาร์ตรวจฝนจริงและฝนที่กำลังเข้า (ส่วนใหญ่ช่วย 0–60 นาที) · แสดง CAPE เตือน "บรรยากาศไม่เสถียร" เมื่อโอกาสฝนต่ำแต่พร้อมเกิดฝนฟ้าคะนองเฉพาะที่ · ถ้าเรดาร์เห็นฝนแต่โมเดลไม่เห็น หน้าเว็บบอกตรง ๆ ให้เชื่อเรดาร์ |
| เวลาไม่ตรง | Open-Meteo รายงานฝน "ของชั่วโมงก่อนหน้า" ป้ายเวลา — ที่ผ่านมาอ่านเลื่อนไป 1 ชม. | แปลงเวลาให้ตรง · เวลาเริ่มตกคำนวณทีละสมาชิก ensemble แล้วแสดงเป็นช่วง |
| ปริมาณไม่ตรง | ใช้ค่ากลางของทุกสมาชิก ทำให้วันที่โอกาสฝน 49% ได้ "0 มม." | แสดง "**ถ้าฝนตก** ราว X–Y มม." แยกจากโอกาสฝน · ยอดรวมสัปดาห์รวมรายสมาชิกก่อนหาค่ากลาง (ตัวเลขเดียวกันทุกแผง) |

**Super-ensemble:** รวม ECMWF ENS (51 ชุด) + NOAA GEFS (31 ชุด) + DWD ICON-EPS (40 ชุด) ให้น้ำหนักเท่ากัน*ต่อระบบ*
(ไม่ใช่ต่อสมาชิก) · ช่วงที่ระบบไหนไม่มีข้อมูล (ICON สั้นกว่า) ปรับน้ำหนักใหม่ ไม่นับเป็น "ไม่ตก"

**Radar nowcast:** ดึงภาพเรดาร์ RainViewer 3 ภาพล่าสุด ถอดสี (Universal Blue) เป็นระดับ dBZ รอบจุด (~57 กม.) หาการเคลื่อนที่ด้วย block-matching
แล้วย้อนตามทิศทางหาว่าเมฆฝนจะถึงจุดนี้เมื่อไหร่ — เชื่อได้ราว 30–60 นาที เพราะไม่รู้ว่าเซลล์ฝนจะโตหรือสลาย

**แหล่งข้อมูลต้องบอกสถานะเสมอ:** ทุกแหล่งแสดง ✓/✗ พร้อมอายุข้อมูลบนหน้าเว็บ ถ้าแหล่งไหนล่ม ส่วนที่เกี่ยวข้องจะบอกว่าใช้อะไรแทน
(เช่น ไม่มี ensemble → ใช้โมเดลเดี่ยวและติดป้ายเตือน) ไม่แสดงตัวเลขเงียบ ๆ จากแหล่งที่เชื่อถือน้อยกว่า

### สิ่งที่ยังทำไม่ได้ (พูดตรง ๆ)

- ไม่มีเครื่องวัดฝนบนแปลง — ฝน "จริง" ย้อนหลังคือข้อมูลวิเคราะห์ ERA5-Land ไม่ใช่การวัด
  → **มาตรวัดฝนที่แปลง (tipping bucket + ESP32 ~1,000–1,500 บาท) คือคำตอบเดียวที่แม่นจริง**
- ไม่ได้ใช้ข้อมูลเรดาร์/พยากรณ์ของกรมอุตุนิยมวิทยา (TMD) เพราะต้องสมัคร API token — เพิ่มเป็นแหล่งหลักได้ภายหลัง
- Nowcast ไม่คิดการเกิด/สลายตัวของเซลล์ฝน

## 📍 เพิ่ม / สลับพื้นที่

พื้นที่ที่ติดมากับโปรแกรม (ลบไม่ได้): แปลงมะพร้าวคลองวาฬ `11.7563340, 99.7684976` · ต.ไร่เก่า `12.2211831, 99.8770225`

ปุ่ม **➕ เพิ่ม** ค้นหาจากชื่อ (Open-Meteo Geocoding รองรับภาษาไทย) หรือวางพิกัดเอง รองรับ
`12.2211831, 99.8770225` · `12.2211831:99.8770225` · `12.2211831 99.8770225` · `12°13'16.3"N 99°52'37.3"E`
(วางสลับ lon,lat ระบบสลับกลับให้) — เก็บใน localStorage ของเบราว์เซอร์ · ปุ่ม **🔗 แชร์** ให้ลิงก์ `?lat=..&lon=..&name=..`
ติ๊ก "เป็นแปลงมะพร้าว" เพื่อแสดงการวิเคราะห์ความต้องการน้ำ

## 🛠️ โครงสร้างและการพัฒนา

```
index.html          โครงหน้าพยากรณ์ฝน
flood-watch.html    หน้าเฝ้าระวังน้ำท่วมทั่วไทย (แยกต่างหาก)
css/style.css       ธีมสว่าง/มืด (ตามระบบ) mobile-first
js/util.js          เวลาไทย, format, จัดกลุ่มความแรงเรดาร์
js/engine.js        ensemble → โอกาส/ช่วงปริมาณ/เวลาเริ่มตก, ตัดสิน "ตอนนี้" (logic ล้วน มี unit test)
js/radar.js         เรดาร์: ถอด tile, ประมาณความเร็ว, ETA (logic ล้วน มี unit test)
js/sources.js       เรียก API: timeout, fallback, แคช, สถานะแหล่งข้อมูล
js/locations.js     จัดการพื้นที่
js/coconut.js       วิเคราะห์น้ำมะพร้าว
js/analysis.js      บทวิเคราะห์อัตโนมัติ (กฎตายตัว มี unit test)
js/charts.js        กราฟเส้น/แถบ SVG และตารางสี (ไม่พึ่งไลบรารี)
js/radarmap.js      แผนที่เรดาร์ (Leaflet + OpenStreetMap + RainViewer)
js/ui.js, main.js   แสดงผลและตั้งเวลารีเฟรช
tests/              node --test
```

```bash
npm test                      # unit test (ไม่ต้องติดตั้งอะไร ใช้ Node 20+)
python3 -m http.server 8000   # แล้วเปิด http://localhost:8000
```

**ออกเวอร์ชันใหม่:** แก้ `WX.VERSION` ใน `js/util.js` และ `?v=` ของทุกไฟล์ใน `index.html` ให้ตรงกัน
เพื่อบังคับให้เบราว์เซอร์โหลดไฟล์ใหม่ (GitHub Pages ให้แคชได้ราว 10 นาที)

เปิด `?debug=1` เพื่อดูสถานะดิบของแต่ละแหล่งและค่าที่ถอดจากเรดาร์ (แผง "แหล่งข้อมูลและวิธีคำนวณ")

**รอบรีเฟรช:** เรดาร์ 5 นาที · พยากรณ์ 30 นาที · ensemble 60 นาที · ย้อนหลัง 3 ชม. · หยุดเมื่อแท็บถูกซ่อน และดึงทันทีเมื่อกลับมา/ต่อเน็ต
